本机已实际导入，重复导入验证没有生成第二门课程或重复题目。导入在事务中执行，冲突时整体回滚。课程、章节、课时和题目 ID 从包 ID 与资源 key 稳定生成；相同包重复导入会跳过已有课程及其全部章节课时，保留人工修改与发布状态，只为缺失的课程或题目创建草稿。不提供强制覆盖或自动发布选项。输出中的 packageLessonCount 是内容包课时数，不代表导入后数据库一定与内容包完全相同。

## 人工审阅与发布

1. 从审阅稿核对知识定义、学习顺序、例题每一步、正负号、分数与单位；必要时由熟悉该学段的教师修订。
2. 确认你打算采用的地区、教材版本与课程定位；当前标注为“自编示范”，不能直接标成某教材同步课。
3. 用自己的管理员账号进入 `/admin/courses`，找到这门草稿，编辑和核对内容。审核后再决定是否发布；发布前可修改或移除“待审阅”标题。
4. 在 `/admin/questions` 找到配套草稿，逐题审核后发布。当前题库与课程独立管理，没有自动建立“课时—练习”关联；学生按七年级、数学和知识点筛选题目。
5. 发布后用学生账号走一遍选课、阅读、标记完成、答题和错题复习。若需勘误已经有人作答的题，应归档旧题并创建新题，保留历史作答快照。

没有替你发布这门课程；公开学生课程目录不会展示这些草稿。内容可以在管理员页修改，也可以在源 JSON 修改后重新生成审阅稿。重复导入会保留数据库中的人工编辑，因此修改 JSON 不会自动同步覆盖数据库，需明确选择编辑已有草稿或创建新版本。
