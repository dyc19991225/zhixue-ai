# 同步学习入口与产品方向

用户确定产品参考作业帮、猿辅导的学习流程。知学沿用自己的品牌与界面，主线为教材同步课程、练习、错题复习、学情反馈；真实AI接入暂放。参考方向不表示获得第三方教材、题库、品牌素材的使用授权。

## 已实现

- /study为公开同步学习入口，主导航和学生学习中心均可进入。
- 复用现有课程目录，按年级、学科、地区、教材版本、学期及课程权益筛选。课程仍须已发布；课程详情内按章节进入课时，课时内进入关联练习。
- 同步页的练习和错题入口传递所选年级、学科；练习页将这两项写入URL，刷新、返回及切换练习/错题/作答记录时保留。作答记录接口仍为本人全部记录，不声称已按年级学科筛选；课时配套练习仍按课时授权获取题目。
- 无匹配课程或题目使用现有空状态；未登录查看错题和报告仍需登录，不自动选课、开始考试或提交答案。
- 我的课程、教师任务、家长概览和管理员入口保持现有权限。教材版本来自实际课程元数据，不推断覆盖范围。
