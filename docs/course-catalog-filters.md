# 已发布课程目录筛选

`/courses` 支持年级、学科、适用地区、教材版本、学期、免费/会员课程筛选；搜索匹配课程名称、简介和中文学科名。输入后按“搜索”或回车应用，清除搜索框同样应用空搜索。每页9门课程，数据库统计完整匹配数量，超过100门也可继续分页和搜索。

筛选条件与页码写入URL，可刷新、返回或分享。改变筛选条件回到第一页，切换年级重置其他条件。“清空筛选”保留当前年级。学科卡片进入带当前条件的目录；首页显示当前年级前3门课程，学科数量使用完整统计，不以显示卡片数量代替总量。原独立学科页也增加分页。

## 元数据与空状态

课程卡片显示编辑者实际填写的地区、教材版本与学期，未填写项不自动推断。筛选选项仅来自所选年级的已发布课程，去除空值；不随当前其他条件收缩，避免选项因暂时无结果而消失。不同组合可以得到空结果，不表示该地区或教材版本没有官方课程。填写元数据不等于平台已核验当地教材选用、版权或完成教材适配。

## API

`GET /api/published-courses` 保留 `items` 与原grade/subject参数，新增page/pageSize/q/region/textbookEdition/term/access。默认page=1、pageSize=100兼容旧调用，最大100；目录页面指定9，首页指定3。响应 `PublishedCatalog`：items、page、pageSize、total、facets、subjectCounts。

地区/版本/学期精确匹配，标题与简介不区分大小写包含匹配；中文学科搜索映射到实际subject标识。列表按updatedAt倒序/id升序稳定排列。总量与本页数据、按年级聚合的元数据选项和学科数量在同一RepeatableRead事务中读取。subjectCounts应用其他筛选但不应用subject自身，供学科导航使用。

公开列表只读PUBLISHED，明确选择课程元数据和章节/课时标题，不返回课时正文、视频编号、服务器路径、教师归属或审核历史；会员课仅公开目录，不改变正文/视频的会员鉴权。未知参数、非法分页和超长筛选返回400。未修改原课程元数据或发布状态，无数据库迁移。

## 验证

`npm.cmd run test:catalog` 纳入verify。105门合成发布课程及独立草稿/归档/其他年级样本按精确ID清理，覆盖超过100门分页、后页课程搜索、组合筛选、中文学科/英文大小写/简介搜索、真实数量、元数据选项隔离、空值、私有字段不泄露及非法查询。`test:learning` 回归学习及会员正文边界。

浏览器使用独立合成课程验证筛选、第二页、刷新/返回、组合空状态、清空及390px布局。合成目录只用于验收，不代表正式教材内容或真实教研结论；原3门课程保持原状。
