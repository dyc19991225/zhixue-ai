# 管理员界面验收

本次使用 `http://localhost:3000` 的独立测试会话，和用户 `http://127.0.0.1:3000` 的现有登录隔离。没有提升用户账号权限，没有调用真实模型、购买服务或部署。

## 浏览器已实际操作

- 临时管理员登录，进入课程、题库与权益工作台。
- 上传 MP4，创建课程、章节与课时，将视频绑定到课时，保存草稿并发布；已发布课程不能直接编辑。转回草稿后，名称、正文与视频选择能正确回填，修改正文后再次保存成功。
- 创建四选一单选题，填写选项、正确答案及解析，保存后确认发布成功。
- 向临时学生授予 7 天测试权益，表格显示有效；确认撤销后显示已撤销且撤销按钮禁用。再次授予后显示成功提示，账号输入框清空。
- 上传中文命名的 MP4，课时选择器显示原始文件名；选中并保存后重新编辑，绑定仍正确。
- 390px 手机文档未横向溢出；桌面流程未发现浏览器 warning/error。表格在各自滚动区域内展示。

截图中的课程、账号、题目和权益均为临时验收内容，已清理，不是默认账号或正式课程。

## 本次修正

1. 视频上传现在携带原始文件名；服务端进行解码、长度与控制字符验证、移除目录部分，再作为素材显示名保存。实际文件仍使用随机存储键，浏览器不接触服务器目录。未提供文件名的旧 API 请求继续使用时间命名。

本次 typecheck、lint、test:foundation 和 build 已通过，临时资源已清理。未扩大测试到真实模型或外部云服务。
