# 逐课配套检查与题库直达（2026-11-08）

管理员可从内容准备度进入/admin/lesson-readiness。默认只看缺少已发布题的课时，按年级、学科筛选，支持课程ID限定、每页20条和URL保存条件。仅列已发布课程中publishedAt非空的课时，包含会员课；显示课程/章节/课时名称及已发布、草稿、归档关联题数。草稿和归档题不抵消缺口，已有题不等于数量足够或教研通过。

从“审阅该课草稿题”进入/admin/questions，按lessonId、grade、subject、status联合筛选。管理员题库新增年级、学科和状态控件，可取消课时限定、清空筛选。条件变更重置分页和编辑器；旧异步读取不回填新的筛选或身份页面。新建题目时预选已验证存在的课时及年级/学科，仍需手工核对、保存草稿和确认发布，页面不会自动创建、审核或发布。

课时选项原先最多300条，现支持includeId保证指定课时被纳入，结果最多301条；课时信息未载入或不存在时禁用该范围的新建入口，避免静默丢失关联。公开练习接口仍不接受lessonId/status管理参数。

后端GET /api/admin/lesson-readiness为管理员只读接口；同一RepeatableRead事务执行分页/总数与当前页关联题分组统计，不加载课时正文、题干或答案。题库管理查询沿用原管理员权限，严格新增参数校验。课时选项仍要求管理员；没有开放新的公开内容接口或修改数据库结构。

实际盘点七年级10个缺题开放课时：每个都有现存草稿题，共30条草稿题关联。关联计数不等于去重题数，同题可关联多个课时。报告位于work/current-lesson-readiness.json。真实发布状态未改变，下一步需逐题审阅并由管理员手工决定是否发布。
