## 使用

打开 http://127.0.0.1:3000/photo-question 并登录。选择题目照片，先裁掉姓名、学校等信息。文字 OCR 在浏览器内完成，也可直接勾选“同时附上当前照片供模型分析”，点击“将题干与照片填入提问框”。核对待发送的图片预览与问题，再点击“请老师给个提示”。选择照片、裁剪和填入不会自行调用模型。

原始照片最多8MB；浏览器处理后的模型附件最多500KB。过大时需继续裁剪。可在提问前移除附件，“开始新问题”也会清除待发送照片。切换身份清除页面状态。

## 数据与额度

明确附图时，照片和题干经本站转发至配置模型。本站不持久保存图片文件，仅在 AiTurn 保存 SHA256 指纹，供重复请求校验；文字问题和回答仍按原有规则保存。模型/反代服务的数据处理规则分别适用。历史接口不返回图片或其指纹。

复用每用户/全站每日调用计数和鉴权。计数限制不是货币预算；失败请求依既有逻辑退回用户次数，不退全站调用预留次数。相同请求标识、问题和图片只调用一次，换图片须使用新请求标识。保持 AI_ENABLED 与 AI_IMAGE_ENABLED 独立开关；关图片仍可文字提问。
