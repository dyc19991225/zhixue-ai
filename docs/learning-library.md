# 我的选课记录

学习中心的“我的选课记录”支持课程名搜索、全部/待开始/学习中/已完成筛选和每页6门分页。搜索与筛选在数据库中执行，最多20条/页；筛选中的数字是当前搜索范围内的完整数量，不是本页长度。按最近保存进度倒序排列，无进度时按选课时间倒序；空结果可清空筛选或前往课程目录。

## 进度与继续学习

仅统计当前仍已发布课程的已开放课时。存在已保存进度但未全部完成为“学习中”，全部开放课时完成且总数大于0才为“已完成”；没有开放课时显示“待开放课时”，不能把0/0当作已完成。保存位置不换算为学习时长，纯文本阅读未保存完成状态时不虚构最近阅读时间。

继续学习优先进入最近保存过进度的未完成开放课时，否则进入按章节/课时顺序排列的首个未完成课时；全部完成后可从首个开放课时复习。课程详情、学习导航与公开目录也过滤未开放课时。历史隐藏/跨课程进度不计入当前数量、时间和播放位置响应，原记录不删除。

会员到期后仍显示本人课程名和进度摘要，标记“需要有效会员权益”，入口指向权益页；不会返回继续学习课时ID或正文。权益有效时重新允许继续学习，撤销/过期后下一次读取重新判断。原正文、视频及进度写入鉴权保持有效，没有自动续费、购买或权益授予。

## API

`GET /api/learning-library?page=1&pageSize=6&state=ALL&q=` 需要有效登录，仅取当前账号自己的选课，无userId参数。pageSize最大20、q最长120，拒绝未知字段。响应 `LearningLibrary` 并设置 `Cache-Control: no-store`。标题包含搜索按字面值且不区分大小写，百分号不视为SQL通配符。

RepeatableRead事务中核验账号、聚合已开放课时和属于该课程的进度、统计状态数量并分页。只有本页最多20门查询继续学习目标，不读取所有正文。会员有效性复用现有时间/撤销/有效计划条件。旧 `/api/learning` 接口保留，学习中心改用新分页摘要接口。

前端使用带账号身份隔离的请求hook，换账号重新挂载课程列表；提供加载、错误重试及手动刷新。不自动修改任何学习记录，课程名搜索/进度筛选改变时回到第一页。

## 验证

`npm.cmd run test:library` 已纳入verify。随机合成账号、独立课程与权益计划按精确ID清理，覆盖四类页面状态（含无开放课时）、最近未完成目标、完成后复习、搜索/分页、超过100门选课、跨账号隔离、失效会员保留摘要与正文拒绝、未开放/跨课程进度排除、公开与学习导航一致，以及严格查询参数。`test:learning`、`test:foundation`和`test:catalog`同步回归。

浏览器使用独立localhost源及合成学生，验证进度筛选、第二页、清空、继续学习与390px布局，不替换用户127.0.0.1会话。原3门课程、原用户和进度记录保留。
