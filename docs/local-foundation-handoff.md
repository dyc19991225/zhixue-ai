## 视频存储边界

默认视频位于被 Git 忽略的 `.local-media`，可通过后端 `MEDIA_DIRECTORY` 改到指定本机目录。浏览器与公开列表不返回文件路径；每次播放先通过已登录、已选课和课程权益检查，再发放 30 分钟、限定媒体路径的 HttpOnly / SameSite Cookie。每次分段请求重新验证会话、发布状态与权益；撤销会话或权益后，后续读取被拒绝。已经下载到浏览器的字节无法远程收回。

支持单文件 MP4，200MB 上限，检查容器标识，使用流式写入和 HTTP Range。编码须由目标浏览器支持；不提供转码、内容扫描、字幕编辑、分片上传或断点上传。素材仅展示最近 100 个，没有自动删除未引用素材；请保留本地媒体目录备份。当前存储实现是本机文件，OSS/七牛实际适配与云端凭据尚未接入。

## 启用真实 AI 前需要你决定

选择有权使用的模型服务、确认预算与数据发送范围，在本机 `.env` 中配置以下变量，密钥不要粘贴到聊天或提交到 Git：

```dotenv
AI_ENABLED=false
AI_BASE_URL=https://你选择的接口地址/v1
AI_API_KEY=
AI_MODEL=
AI_USER_DAILY_LIMIT=20
AI_GLOBAL_DAILY_LIMIT=100
```

适配器调用 `${AI_BASE_URL}/chat/completions`，使用 Bearer 认证与常见的 messages / choices.message.content JSON 格式。必须确认服务支持该协议；不同模型的参数兼容性仍须针对所选服务验证。正式环境只允许 HTTPS；本地模拟测试允许 localhost HTTP。

填写并检查配置后，将 `AI_ENABLED` 改为 `true`，重启 API，`/api/ai/status` 才会显示已配置。**本次没有替你启用，也没有进行真实付费调用。** 先用少量固定教学题验收质量，再决定是否给真实学生开放。

当前为单轮问答，每次只发送系统辅导提示与主动提交的问题，不附带账号或自动发送历史记录/课程正文。问题限 2000 字符，输出限 700 个 token，请求 25 秒超时，不自动重试外部调用。默认个人每日最多 20 次，全站最多 100 次外部调用尝试，按 UTC 日期切换。失败退还个人成功次数，但不退全站调用预算；并发重复提交只触发一次外部请求。全站次数上限不是货币费用上限，供应商价格、账单及账户侧额度需自行设置。

已完成记录可在页面清空；处理中记录保留。若进程中途退出，PENDING 记录不会自动重发，也不会自动退还配额，以防重复付费调用。历史页面最多显示最近 30 条。AI 不包含检索教材依据、多轮上下文、自动评分、工具调用或正式内容安全/教学质量评测，不能视作完成商业化 AI 老师。

## Docker / Nginx 准备情况

Dockerfile 提供 api 和 web 两个目标，Node 24 Debian 基础镜像包含 OpenSSL/CA，API 以非 root 用户运行。Nginx 提供 SPA 路由、视频分段代理与上传限制，访问日志不记录查询参数。只信任受控的一跳代理，Nginx 覆盖转发来源头；直接本机 API 默认不信任客户端伪造代理头。

两个最终本地镜像均已构建成功；在无网络、无发布端口的临时容器内，Nginx `-t`、后端入口语法检查与 Prisma CLI/OpenSSL 检查均通过。没有在容器内执行连接现有数据库的应用栈端到端验收。

本地构建和配置验证命令，不启动对外服务：

```powershell
docker compose -f compose.yaml -f compose.app.yaml --profile cache --profile app config --quiet
docker build --target api -t zhixue-ai-api:local .
docker build --target web -t zhixue-ai-web:local .
```

compose.app.yaml 是待审阅的容器运行配方，**没有执行应用栈启动或部署**。它仅发布 web 到本机 8080，API 和缓存不对外发布。生产 Cookie 强制 Secure；要实际用于登录，仍需配置 HTTPS 入口与匹配的 APP_ORIGIN，不能把这个 HTTP 配方当作已完成的生产方案。生产数据库连接字符串使用容器服务名；使用自定义含特殊字符的数据库密码时须先完成 URL 编码。不要使用 `docker compose down -v` 删除现有数据卷。
