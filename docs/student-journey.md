# 学生跨模块自动验收

2026-11-06新增 `test:journey`，已纳入根目录 `verify` 串行检查。

```powershell
Set-Location E:\projects\zhixue-ai
npm.cmd run test:journey
npm.cmd run verify
```

需要配置好的本地 PostgreSQL、Redis 和已应用的迁移。测试不调用真实 AI，不访问云存储。

## 验收范围

使用随机合成账号、班级和课程副本，通过真实 HTTP 路由串联流程。账号角色、班级名单和家长绑定是数据库测试夹具；课程发布、选课、学习、作答、批改、考试与学情走应用 API。

| 环节       | 断言                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------- |
| 学习       | 复制现有原创包的一课，发布副本并选课，正文一致；重复完成只有一条记录且时间不变                |
| 练习       | 一错一对，正确率50%，错题已解决                                                               |
| 作业       | 使用往返书面题，提交参考过程，教师模拟人工批改8/10；学生能读取反馈                            |
| 考试       | 复制20道单选、3张受控题图；保存、交卷，结束前学生及家长均无分数，关闭后100/100且解析/图形一致 |
| 学情       | 本人、绑定家长及所属班级测评分数一致；书面80%与考试100%分别统计                               |
| 趋势与导出 | 7天趋势与各CSV数据行一致；班级不含私人练习；未绑定及解绑后访问均拒绝                          |
| 清理       | 按确切ID清理合成测评、班级、题目、课程、审计及账号，结束时断言合成账号已删除                  |

共6个测试计数（1个父测试和5个阶段），不是6名学生实测。合成评分是协议验证，不是教研质量结论。原始课程若存在，验收前后完整记录必须一致；不要求预先导入草稿即可运行本测试。

## 课时练习与错题复练（2026-11-18）

在课时页选择「完成本课并去练习」，进度保存成功后打开该课时的配套练习。答错可直接进入「复练本课错题」，答对后可查看「已答对」。课时、复练状态和分页保存在链接中，可刷新后继续，也可从练习页返回原课时。

本课错题只包括本人错题本中与该课时关联的已发布题。共享题在它关联的开放课时中都可复练。课时练习与复练沿用选课、发布和会员权限，提交前均不返回答案或解析；全站错题本仍可照常使用。

`test:journey` 读取现有七至九年级课程包，以临时副本逐课验证完成进度、配套练习列表、答错入本课错题、答对移入「已答对」。每个课时必须至少有一道配套题。测试同时检查课时、账号与会员权限，并核对练习和复练列表在作答前不返回答案或解析。

当前源码中七年级 11 门课（数学 9 门、英语 2 门），共 44 个课时、98 道配套练习，每课至少 1 道，无需补题。八、九年级的 4 门课、16 个课时继续覆盖。盘点和验证以仓库内容包为准，临时副本只用于测试数据库。

## 学习中心的待复练

学生可在 `/dashboard?tab=review` 按课程和课时查看本人未答对的错题。课程按最近答错时间排序，课时按课程目录顺序排列。课时行直接进入已有的本课错题页，返回待复练列表时会重新读取计数。

`GET /api/learning-review-queue?page=1&pageSize=6` 只返回已选且可访问的已发布课程、开放课时和未解决的已发布题目计数。课程内同一道共享题只计一次，各关联课时各计一次。没有关联课时的错题仍可在全站错题本查看。接口仅限学生本人，分页按课程，不返回题干、答案或解析。

点击「开始复练」会重新读取待复练队列，打开排在最前面的课时；当前课时仍有未答对的题时继续留在本课。全部答对后保留答案解析，学生可点击「下一课复练」。下一课优先从当前课程按目录顺序选择，当前课程清空后按课程队列继续。点击时再次校验题目状态与访问权限；分页里的剩余题可从「继续复练本课」重新载入。全部完成时提供返回待复练列表的入口。

`GET /api/learning-review-queue/next` 提供首个可复练课时。可同时传入 `courseId` 和 `lessonId` 查询当前剩余题数与下一课入口；只返回本人可访问的课时和计数。
