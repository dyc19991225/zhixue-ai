# 拍照解题完善（2026-11-07）

## 本轮行为

- 附图前在浏览器压缩JPEG：逐步调整质量和长边，限制解码后附件不超过512000字节；OCR源图不被压缩结果覆盖。仍过大时要求裁剪，不偷偷发送原图。小尺寸图片不被放大。
- 图片处理与提问互斥；双击提交有同步锁。更换、清除、旋转、恢复或调整裁剪范围后清除旧的待发送附件。未应用裁剪不能附图。识别把握较低时提醒逐字校对；此提示不是解题正确率。
- 明确勾选附图，填入并核对预览，再点“分析照片并解题”。完成后显示本次回答区，原有本人历史记录保留。图片不会自动提交。
- 图片问题使用题意与已知、先想一想、解题步骤、检验与结论的回答要求，明确不凭示意图外观推断直角/平行/等长；模糊、截断、条件不足或多题需说明并请求补充。此为提示要求，不是模型结果的形式或正确性保证。
- 图片回答上限1200 tokens，文字问题仍700；模型返回长度截断信号时显示未讲完整提示，不静默展示为完整答案。
- 失败保留问题与附件。通过新增 GET /api/ai/questions/:requestId 查询本人请求状态：已失败时允许用户明确点击重新解题（新标识）；状态不明时保留原标识，不自动重新调用模型。查询不返回图片、指纹或其他用户记录。

## 已验证

真实模型 workbuddy/deepseek-v4.1-flash 经应用 askTeacher 调用两张原创合成图片：

1. geometry-right.png：AB=3、AC=4，A有明确直角标记，回答BC=5，并说明正边长和条件。
2. geometry-insufficient.png：同样给两边，无直角标记且明确示意图不按比例，回答不能唯一确定，给出1<BC<7，未擅自认定直角。

原图位于 apps/web/test-fixtures，模型原始文字结果保存在本机 work/photo-geometry-evaluation.json。验收账号与对应记录按精确ID清理；真实调用的全站次数计数保留，不影响真实课程。两例通过不代表总体准确率，不代表复杂几何或手写已可靠。

桌面浏览器实测将1,221,528字节的处理图压缩至444,840字节（1800×1309降至1440×1047）；原OCR源图保留。裁剪改动立即移除旧附件、禁用填入；新图片需重新勾选。几何图片附加、清除及390px页面无横向溢出检查通过。页面未借真实账号提交模型请求。

智能透视矫正、自动多题切分、多图提问、可靠手写/复杂公式识别、数学公式排版、真实手机相机权限与拍摄验收仍待后续。当前每次为独立单题提问，没有多轮上下文。模型服务超时仍25秒；不会因重试自动放宽额度或无限重发。照片是否可解需要逐题核对，保留人工复核入口。
