# 学生学习待办

学生登录后，在 `/dashboard` 的“学习记录”中查看待交作业和待参加考试。每类按截止时间升序展示最近5项，同时显示完整待办数量；可手动刷新，每分钟及窗口重新获得焦点时自动更新。时间按北京时间显示。

作业入口直接打开 `/homework?homeworkId=...` 的详情，关闭时清除参数；考试入口只打开考试说明页，不创建作答或开始计时。考试开始仍需学生确认。

## 数据与访问口径

`GET /api/analytics/me/tasks` 只允许当前有效学生，无目标学生参数。返回 `StudyTasks`，设置 `Cache-Control: no-store`。在同一个 RepeatableRead 事务内重新检查身份、读取计数和限量列表，不读取所有历史记录。

- 作业：已发布、分配名单包含本人、未提交、尚未截止。
- 考试：已发布、分配名单包含本人、尚未截止；未开始或已开始但未交卷且个人计时未结束。未开考显示“未开考”，已开始显示“答题中”，后者截止时间为个人结束与全卷截止中较早者。
- 两类任务都要求班级未归档、教师仍有效且角色为教师、学生仍在有效班级名单。退班后的历史仍可按原业务规则查看，但不再列为待办。
- 已过期任务不列入数量，未交卷但个人计时已结束的考试也不列入。此接口只读，不触发交卷、补交、自动批改或修改发布名单。
- 不返回作答、答案、成绩、反馈或账号凭据。计数不包含课程学习进度，也不是历史未完成任务总量。

## 验证

`npm.cmd run test:tasks` 使用随机合成账号、独立班级及任务，按精确ID清理；覆盖完整计数与前5项排序、过期/已交/草稿排除、个人计时、本人隔离、角色限制、非法目标参数、退班/归档/教师失效，以及接口不会自动开始或交卷。已纳入 `npm.cmd run verify`。

浏览器验收使用独立 localhost 源及合成学生，避免替换用户在127.0.0.1的会话。真实用户、原课程及发布状态保持原样。

## 家长只读待办（2026-11-07）

家长登录学习中心后可选择管理员已绑定的孩子，查看学习概览及相同口径的待交作业、待参加考试。原 `/parent/students` 页面也接入此待办。选择仅从当前账号当前页的有效绑定列表派生；换账号、换孩子或翻页时不会复用旧孩子的概览和待办。刷新绑定列表会重新载入所选孩子的数据。

`GET /api/analytics/students/:studentId/tasks` 仅允许有效家长，在同一个RepeatableRead事务中重新检查绑定未撤销、目标仍是有效学生，再复用学生待办统计；禁止未知查询参数，响应 `Cache-Control: no-store`。解除绑定、禁用学生或改变双方角色后，下次请求立即拒绝。界面每分钟及窗口重新获得焦点时重取待办；已有画面不宣称具备实时撤回能力。

家长待办仅显示名称、班级、截止/开考时间、状态及数量，不展示作业正文、学生作答、题目、答案、成绩或教师反馈，也不提供学生作答链接。家长不能借此代交作业、开始考试或修改绑定，原有后端角色限制保持有效。每类最多5项，数量统计覆盖全部有效任务。

`test:tasks` 已增加家长绑定、双孩子切换、跨家长隔离、解绑、学生禁用、角色变化及禁止代交/开考的验证；共享统计的原学生用例同时回归。
