# 拍摄、照片微调与解题记录（2026-11-07）

本轮继续完善本机拍照解题，不改变模型配置、权限、课程或发布状态。

## 新增操作

- 后置摄像头入口使用浏览器文件选择与 capture=environment 提示。支持的手机浏览器可调用相机；桌面或不支持的浏览器显示文件选择，不宣称已完成真实手机拍摄验收。
- 点击题图可打开本地放大预览。预览窗口里的旋转/翻转只用于查看，不改变待识别图；实际修改使用页面按钮。
- 倾斜微调范围-15°到15°，按旋转后的完整边界绘制，四角不被直接裁去，长边最多1800px，不放大小图。黑白对比增强为可选项，会将彩色标注转灰；用户可恢复原图。
- 微调先应用再识别或附图。裁剪待应用时不允许调整微调参数，微调待应用时不允许改变裁剪范围，避免不清楚处理顺序；任一编辑继续清除旧题干与待发送附件。
- 当前成功解题和本人成功历史记录可复制题目与答案、下载含核对提示的TXT，均不包含照片。复制失败有手动选择/下载提示。校对入口把题干放回输入框，不自动提问，不自动重新附图，明确提示再次提问将产生新调用。
