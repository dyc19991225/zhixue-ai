# 湖北优先、多版本教材来源清单

核验日期：2026-11-06。范围：初高中，湖北全省多版本。

## 已完成与边界

- 人教社初中85条、高中107条官方目录阅读链接，共192条。链接逐页记录，非192册均逐页阅读验收。
- 抽查人教七年级数学上册：从出版社页面点击可打开202页阅读器；部分直链会触发原站来源校验，应从原站目录进入。
- 两份湖北官方价格目录共1048条原始书目记录（2026春497、2025秋551），保留跨学期重复项与小学/图册/地方课程；不是1048册不同初高中教材。
- 国家平台初中数学、英语、物理、化学、生物学、地理多版本筛选已核验；这些是全国目录，未全部确认为湖北市校正在使用。
- 未取得覆盖湖北所有市州/学校、全部学科的2026秋完整实际选用表；不能宣称全省版本已完全配齐。
- 未复制教材正文、整本PDF、题目或配套视频进知学课程；既有草稿和账号未改动。
