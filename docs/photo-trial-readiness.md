# 拍照识题与小范围试用

## 本轮交付

- /photo-question：本地OCR识别中英文印刷体文字，选择JPG/PNG/WebP，文件上限8MB、解码尺寸上限2000万像素，处理图像最长边1800px。浏览器重绘去掉原始元数据，只将重绘后的图片留在内存。照片不上传、不保存；识别文字需校对，再由按钮填入AI提问框，不自动提问。真实AI仍关闭。
- 识别用Tesseract.js 7及本地中英文语言文件，资源随前端部署，不使用外部CDN。第一次加载有语言及WASM开销，较弱设备可能耗时；90秒超时允许重试。支持取消、清除与重新选图，异步结果有版本检查，避免取消后旧结果回填。初始化中的worker在创建完成后再检查版本并终止。
- /trial：20分钟试学路线、五项自查、问题范围/影响程度/重现步骤、下载本地反馈单、清空。没有发送邮件、云端保存、自动登记或统计。清单仅当前页内存，勾选不代表系统验收，也不修改真实学习记录。
- 页脚提供试用入口，同步页提供拍照入口；隐私说明补充了OCR数据流。
- 数据与统计草稿：content/courses/g7-open-statistics.v1.json，2章4课时8题，含频数、平均数、中位数和众数。开放来源固定版本及CC BY-SA 4.0随正文解析保留，截图图片不转载。内容定位为基础/拓展，不将所有统计知识声称为七年级必学。
- npm run content:coverage只读盘点数据库所有年级学科的课程/题目发布和草稿数量，写入work/content-coverage.json。统计数量不是教材覆盖率，也不证明课程质量。

## OCR限制

它是文字识别，不是题库检索、自动解答或几何理解。手写、根号、上下标、分式、表格及多栏排版可能出错。需先在手机相册裁剪、摆正单道题，再核对数字、符号、单位和选项。暂未实现页面内拖拽裁剪和智能透视校正。模型关闭时，填入文字后也不会产生答案。

## 技术验证

test:ocr使用一张本地合成PNG，实跑中英文OCR并核对“3x+2=11”和“求解方程”；该测试已纳入verify，不能据单张图片宣称识别准确率。前端类型检查、构建及lint通过；浏览器实际完成选图、识别、填入提问框、刷新清理、取消清除。桌面和390px布局已查看。

试学页在浏览器验证勾选、下载及清空，生成合成反馈示例；无真人试用。统计课导入前备份，8题按原数据独立核算，校验、预览、两次幂等导入及test:content 5项通过。未重跑全部业务测试，未进行真机相机权限与拍摄验收。

## 运维安排与待填事项

小范围试用前由运营负责人填写以下实际资料，不用虚构联系方式或主体：

| 事项 | 当前状态 | 需落实 |
| --- | --- | --- |
| 试用范围 | 本地原型，非公开招生 | 确定人数、年龄、监护人参与方式和试用日期 |
| 运营与支持 | 未提供正式主体/支持联系方式 | 确定负责人及用户能找到的支持入口 |
| 内容把关 | 原3门公开课；新增草稿不对学生开放 | 教师审阅、独立管理员审核；另行审核发布题库和开放课时 |
| 练习可用性 | 当前库中公开题数为0 | 发布经审核的配套题后，才安排真人完整练习/错题试用 |
| 反馈处理 | 本地下载，不自动送达 | 用户自行交管理员，管理员按严重程度建记录；不把下载显示成已受理 |
| 账号/数据请求 | 无自助注销、全量导出或自动清理 | 确认身份核验、保存期限、删除边界和备份处理后再实现，不能承诺立即删除 |
| 监控与备份 | 手动巡检/联合备份/隔离恢复已有 | 明确值守人、维护窗口、异地存储、定时执行和通知渠道 |
| 付费与AI | 无支付；真实AI关闭 | 本次试用不收费、不收款；模型和费用另行配置验收 |

隐私/权限疑似泄露或答案关键错误应先停止受影响流程，管理员只收集必要的复现信息，不索取密码、恢复码或真实学生照片。确认问题和修复后再恢复试用。这里是执行准备，不代表正式隐私政策、监护人授权或上线法律事项已完成。

## 课程覆盖后续

截至本轮盘点，仅七年级数学有课程：3门公开、6门草稿，题库82道草稿、0道公开题。其他年级和语文、英语等学科尚无课程，不称全学科覆盖。下一轮先审核已有基础主题及配套题，再按具体教材版本补章节映射；跨年级、跨学科需建立相应内容与教师审阅，不以菜单里的学科数量代替真实内容。

## 构建与许可

predev/prebuild运行scripts/prepare-ocr.mjs，将npm依赖中的worker、WASM和语言文件复制到忽略提交的apps/web/public/ocr，Docker在构建阶段同样生成。复制资源约76MB，浏览器按需加载；源包不含生成副本。复制Tesseract与core的许可；语言数据源许可存于content/sources/ocr/tessdata-LICENSE.txt并随前端提供。依赖审计报告中的moderate项目涉及现有路由/检查工具，未自动执行破坏性升级；本轮没有报告为零漏洞。
