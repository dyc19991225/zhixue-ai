# 管理员题库文字检索

2026-11-08：`/admin/questions` 新增题干、知识点文字输入和难度选择，沿用年级、学科、状态、课时及分页条件。

- 文字需点击“搜索题库”或回车应用；题干非空时2..120字，知识点最多80字。未提交的修改有提示。
- 两项文字按连续子串匹配，大小写不敏感；管理员查询的 SQL `%`、`_`、反斜杠按字面处理。只查题干/知识点，不查答案解析，不是语义或图片搜索。
- 搜索/筛选回到第一页，保留课时限定；“重置文字”只移除两项文字，“清空筛选”清除全部条件。
- URL保存已应用条件，刷新恢复输入；服务端每页12题与总数来自数据库。逐题预览仍限当前页并在改变条件后清除。
- 管理接口仍需管理员。公开练习不接受lessonId/status等管理参数；真实课程题目不自动审核或发布。
