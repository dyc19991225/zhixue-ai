# 第一期范围与实施任务

> 当前工程已迁移为 React 18 + Ant Design + React Router v6 / Express 前后端分离架构，最新目录与接口以 `architecture-migration.md` 为准。下方“本次交付”记录的是最初 Next.js 骨架阶段；后续业务里程碑顺序仍适用。

## 本次交付（第 1 个里程碑：工程与页面骨架）

- Next.js App Router + TypeScript strict + Tailwind CSS，npm 锁文件。
- 中文响应式首页、全站导航、移动菜单、页脚、404。
- 七至九年级/高一至高三导航、学科搜索、学科详情空状态。
- 学习中心、练习、AI、会员、登录、管理、关于、隐私与使用说明占位页。
- PostgreSQL/Prisma 模型、惰性数据库客户端、未接入 UI 的课程只读仓储、数据库验证脚本。
- 本地 PostgreSQL Compose 配置，仅绑定 127.0.0.1:5433。
- 数据库未运行时，页面仍可独立构建与浏览。

这不是已经可商业运营的完整平台。尚未实现注册登录、权限、视频播放、课程编辑、学习进度、练习、会员权益执行或 AI；所有导航的筹备状态均在页面明确说明。

## 推荐顺序（由一人配合 Codex 推进，按验收逐步排期）

1. 工程基线：本次骨架、样式、构建、数据库准备。验收：页面可启动，核心路由返回正确状态。
2. 本地数据库：启动 PostgreSQL、生成首个迁移并检查表；确认地区、教材版本、学期和学制。验收：空库迁移成功、读取真实课程且草稿不展示。
3. 账户与权限：选定认证方案、学生/管理角色、会话、监护人与数据最小化方案。验收：越权与未登录请求被服务端拒绝，不仅隐藏按钮。
4. 内容管理：课程/章节/课时编辑、审核与发布，上传与内容权属流程。验收：准备一门有授权的课程，从草稿到可学习。
5. 学习闭环：选课、课时阅读/播放、进度保存与继续学习。验收：刷新和重新登录后进度保持，不可跨账号读写。
6. 练习与会员骨架：题目、作答、错题；先完成免费/会员访问控制。验收：答案校验与权益到期判定正确。支付需另行明确授权与方案。
7. 基础版本验收：业务测试、移动端、键盘导航、备份恢复、错误记录；具备条件后另行讨论部署。
8. 第二期 AI：后端代理、内容依据、引导式教学、质量评测、限流、费用上限与数据边界。

## 数据模型约定

User → Enrollment → Course → Chapter → Lesson；LessonProgress 关联 Enrollment 和 Lesson；Membership → MembershipPlan。

- 默认课程草稿、会员计划关闭；没有默认管理员，没有真实用户种子。
- 用户表暂不保存手机号、密码、真实姓名或学校等信息；认证字段待方案确认后添加。
- Grade 的 G7–G12 目前对应六三学制导航，不作为全国统一教材/开课结论；地区和教材字段预留，五四学制需扩展。
- 课程仓储只返回已发布课程的列表元数据，没有开放 HTTP 写入接口。
- 学习进度写入须校验课时所属课程、选课归属、用户身份与权益；模型本身不等于业务权限。
- 数据库连接与真实迁移未在本次执行：Docker 引擎尚未运行。
